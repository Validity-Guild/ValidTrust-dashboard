# Drips Readiness - ValidTrust Dashboard

This document outlines the Drips readiness for the ValidTrust Dashboard repository.

## Repository Purpose

The ValidTrust Dashboard is the official frontend interface for the ValidTrust Network. It enables users to connect their Stellar wallets and interact with ValidTrust smart contracts.
